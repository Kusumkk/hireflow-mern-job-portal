# 🚀 HireFlow – MERN Stack Recruitment & Job Portal

HireFlow is a full-stack recruitment and job portal application built using the MERN stack. The platform connects candidates and recruiters through role-based dashboards, job management, application tracking, and resume management.

Candidates can search and apply for jobs, upload resumes, track their applications, and manage their profiles. Recruiters can create job postings, review candidate applications, view uploaded resumes, and update application statuses.

---

## 📌 Features

### 👨‍💻 Candidate Features

- User Registration and Login
- JWT-Based Authentication
- Candidate Dashboard
- Browse Available Jobs
- Search and Filter Jobs
- Apply for Jobs
- Track Job Applications
- Upload Resume
- Profile Management
- Application Status Tracking

### 🧑‍💼 Recruiter Features

- Recruiter Registration and Login
- Recruiter Dashboard
- Create Job Postings
- View Candidate Applications
- View Candidate Resumes
- Update Application Status
- Manage Recruitment Workflow

### 🔐 Security Features

- JWT-Based Authentication
- Password Hashing using bcrypt
- Protected Frontend Routes
- Role-Based User Access
- Environment Variables for Sensitive Credentials
